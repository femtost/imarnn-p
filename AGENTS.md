Coding conventions
  - Use common casing for JS
  - CSS properties to be wrapped at 80 characters instead of one line per property.
  - Max line length is 120 unless it's not possible to wrap, eg. HTML anchor tag href
  - Always have blank line above: 'if', 'while', 'for', 'function' blocks
  - Do not indent more than 10 times for whatever logic
  - Must have comments after 5 or 10 lines
  - Must have comments above classes, functions, methods
  - Always use 'if-else' instead of switch-case
  - Always use 'while'-loop instead of 'until'-loop
